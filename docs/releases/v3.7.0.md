Agent Terminal 3.7.0 makes delegation safer to leave running and the app easier to leave. A parent can now declare what a child may do (edit, run commands, reach the network), and anything outside that is refused outright, never asked. A root in dangerous permissive mode answers its sub-agents' approvals and is woken with their results. Sub-agent approvals, questions and forms show in the parent thread, and a Claude sub-agent shows the model it really runs on. `agent-terminal --uninstall` (also in Settings) removes everything the app put on the machine, asking whether to keep your data. Underneath, secrets split across streamed output are never stored, the redactor reads values as shell and YAML words, session grants and the agy hook proof close several bypasses, "Push & Open PR" pushes where git would, and a long live session stays cheap to resize.

## Before you upgrade

- **No store migration.** The thread store stays at schema 5, so 3.6.0 and 3.7.0 can open the same database.
- **Session grants ask more often.** An `rg` or `grep` session grant now covers a call only when every option is a flag that takes no value, and a folder grant follows the file a path really reaches. Everyday calls such as `rg x .`, `rg -g …`, `rg -A 3 …`, `grep --include …` and `git diff --text` now ask again (see Fixed → Approvals).
- **A plan child has no network unless its parent declares it.** Before, it asked you. With no `capabilities` declared, a writing child now also gets your saved shell rules within its parent's mode, as it already got your edit rules.
- **A root in dangerous permissive mode starts turns by itself.** When its sub-agents finish or report, it is woken with the news like a root in any other mode, and it answers their approvals that offer Allow (once, keeping no rule). The cap on consecutive wakes without you still applies.
- **More text is masked.** Spaced assignments (`DB_PASSWORD = …`, `api_key : "…"`, `:=`, `=>`) and YAML values are masked, so code such as `let token = compute(x);` in a diff or hand-off now reads `****`. A streamed item cut short (turn end, close) loses its last unfinished word to `****`.
- **Settings text rows save when committed.** Command, Environment File and Extra Arguments are validated as you type and saved on Enter, the apply button, focus leaving the row, or a close. A half-typed value is no longer saved after a pause.

## Added

### Delegation

- [feat] **A parent can declare what a child may do.** `cross_agent_spawn` takes an optional `capabilities` list (`edit`, `exec`, `network`): all the child may do beyond reading. It only narrows the task mode (a plan child can hold `network` only; anything else is refused as `invalid_argument`), and a child of a restricted worker never holds more than its parent, inheriting it when it declares none. Any call outside it, and any unrecognised tool, is denied outright, so neither your rules nor dangerous permissive mode can approve it. The declaration is kept in the child's launch record; one that cannot be read restores as nothing beyond reading. The tool description tells agents that a limit written only in the task text is not enforced.
- [feat] **Sub-agent requests in the parent thread.** A supervised sub-agent's pending approvals, questions and forms appear on the parent's pinned shelf, labelled with the worker's name, and the reply goes to that exact worker, process and run. "Review worker…" opens the full request.
- [feat] **Dangerous permissive mode reaches the sub-agents' approvals.** While the root is in it, each live worker approval that offers Allow is answered once, keeping no rule, through the shelf's own route, so the worker's inherited authority is still checked and anything it forbids is still denied. Requests already waiting are answered when the root enters the mode. Questions and forms still wait for you, and a worker never runs in the mode itself.

### Chat

- [feat] **A Claude sub-agent's model.** The sub-agent list and shelf show the model a native sub-agent was started with, and once Claude reports it, the model it actually runs on (also read from imported transcripts). Effort shows as requested; Claude never reports the effective one.

### Uninstall

- [feat] **`agent-terminal --uninstall [--yes | --keep-data]`** lists what it found with sizes, asks `Also remove your configuration and data? [Y/n]`, then removes the program the way it was installed (`apt-get`, `dnf`/`rpm`, `pacman`, or the `make install` files). The default flips to `[y/N]` when another installed copy that stays shares the data. `make uninstall` runs it (`UNINSTALL_ARGS=--yes|--keep-data`).
- [feat] **Settings → General → Uninstall Agent Terminal…** shows the same list, a "Remove Configuration and Data" switch (on by default) and a confirmation; the work runs once every window has closed, the package through `pkexec`.
- [feat] "Configuration and data" means the app's own XDG folders (and the pre-2.0 `antigravity-terminal`), agy's `agent_terminal` MCP registration and allow rules only where the app's journal proves it added them, each Codex profile's `rules/agent-terminal.rules` while it still carries the app's header, and `refs/agent-terminal/*` and `<git dir>/agent-terminal` in every repository a thread ran in. Worktrees, branches and agy's `hooks.json` are never touched. It refuses while an instance runs, under `sudo`/`pkexec`, or with no terminal and no flag.
- [feat] The deb, rpm and Arch packages' removal scripts say where each user's data stays; they never touch a home folder.

## Changed

- [change] **A long live session stays cheap to resize.** The transcript keeps at most 600 built rows, nested sub-agent steps included; a sub-agent card builds its newest 40 steps under an "N earlier steps" button; rows away from the end wait unbuilt until you scroll to them; and collapsed card bodies are no longer measured. At 300 steps per sub-agent card, a live resize went from 21 ms to 4 ms, and applying the session's events took 5.3 s instead of 7.1 s of main-thread time.
- [change] Sub-agent summaries are read again only when what they came from changes (`subagents()` at 300 steps: 133 → 81 µs).
- [change] A switch of agents reads the thread and builds its hand-off on the store writer's thread, so a 6,000-message switch never holds the window for more than 150 ms at a time.
- [change] **Agent profiles remember their agent.** A profile records the agent it was made for, so setting its Command to a wrapper such as `claude-nightly` no longer detaches it and creates a duplicate "Claude". Older files load unchanged.
- [change] The interruption shelf's buttons apply the same fail-closed check as the keyboard: only an offered decision, never Allow for a permission request.
- [change] `passphrase` is a sensitive name to the redactor, and lines with many program words are scanned in linear time.
- [change] The repository no longer carries editor tooling (`.vscode/tasks.json`, which started `claude` on folder open, and a stale `.gemini` skill).
- [change] Large internal consolidation across agent-core, agent-kit, the delegation supervisor, the window and the chat view: shared helpers, dialogs, background jobs, settings rows, the socket accept loop and test fixtures, with behaviour unchanged except where listed here.

## Fixed

### Secrets and redaction

- [fix] **A secret split across streamed deltas is never stored.** Each streamed delta used to be masked on its own, so a token split across two left a part in SQLite. Every delta now goes through a per-item stream sanitiser and is stored only once it can be judged whole; whenever a stream loses its context, what follows is masked until it is back. A hand-off made mid-turn shows a placeholder for text still being judged.
- [fix] The redactor reads values as shell words, YAML and INI values and quoted strings: multi-word YAML values, escaped quotes, joined shell words (`PASSWORD=abc"def"`), a `Bearer` followed by several spaces or a tab, separators attached to `curl`, and mask-shaped prefixes no longer leak.
- [fix] A secret whose name and value are spaced from the separator (`DB_PASSWORD = …`, `api_key : "…"`, `export SECRET_TOKEN = …`, `:=`, `=>`) is masked.
- [fix] A copy kept before a broken or externally edited config is replaced is written `0600`, like the config itself; an older `0644` copy is narrowed when reused.

### Approvals and the agy hook

- [fix] For an agy thread outside a git repository, workspace hook files in every ancestor up to `/` now refuse the hook proof, not only the thread folder.
- [fix] `rg` and `grep` session grants no longer cover calls that search the whole tree (`rg -v -g '!x' README.md`, `rg x .`, `grep --rec needle .`); long options that run code are matched by any unambiguous prefix (`git log --outp=x`); a read rule judges the file a path reaches, so a link into `~/.ssh` asks.
- [fix] A folder grant judges the file the path reaches and holds the folder open: replacing it with a symlink, or deleting and recreating it, no longer carries the grant. A typed folder that does not exist yet is refused with the reason.
- [fix] Git approval cards: `git checkout <rev> <file>` reads as a file restore with the overwrite warning, `git grep -O` as running a program, abbreviated program options are not read-only, and `git reset --keep` warns that the branch moves. `tar --checkpoint=1` gets the code-execution warning.
- [fix] An approval card no longer appears for an agent that had already exited.
- [fix] The agy canary trips on a watched step that ran and then failed or was interrupted, and no longer restarts an agy that had already stopped.

### Delegation

- [fix] Closing a worker, or its process exiting, no longer leaves its siblings stale; before, their every tool call was denied and their messages to the parent failed.
- [fix] A root in dangerous permissive mode is woken with its sub-agents' results. Before, the news was held silently, retried every second and never sent.
- [fix] Stop turn on an approval card stops a delegation root as the window's Stop does, so its sub-agents' news no longer wakes it.
- [fix] A delegation token file and its token are cleaned up when a launch never starts.
- [fix] A delegated child's approval socket, registration checks and authority use one proven home.
- [fix] agy's delegation calls are recognised in snake_case and camelCase as well as PascalCase.
- [fix] A continued Claude sub-agent (`SendMessage`) shows as running on its own card, and its steps are no longer marked failed at the root's turn end.
- [fix] A message sent mid-turn can no longer replay sub-agent news that was given back on a Claude thinking-display retry.

### Threads and messages

- [fix] A message sent while an agent was starting is no longer lost if the start fails: it goes back to the queue with a notice.
- [fix] A message written while an agent switch waits goes only to the new agent; if the switch is cancelled or fails, it is held with a notice and neither agent gets it. Closing a thread with held messages asks first.
- [fix] A Codex `/compact` that is refused or does not compact no longer makes a later automatic compaction read as manual.
- [fix] A hand-off brief for a session with no recorded prompts no longer panics, and a relative `XDG_STATE_HOME` no longer puts briefs under the current folder.
- [fix] A background job left behind by a command can no longer grow an unbounded buffer or pin a thread in the app.
- [fix] agy transcripts are read from the HOME the profile launches agy with.

### Diffs and GitHub

- [fix] **"Push & Open PR" pushes where git would.** The remote and branch follow git's own order (`pushRemote`, `pushDefault`, the branch's remote, `origin`), a feature branch is never pushed onto the base, a branch cut from `origin/main` no longer reads as `main`, and the confirmation shows exactly the command that runs. A push repository that differs from the fetch one shows "may need pushing" instead of a wrong state.
- [fix] A diff without a checkpoint finds the file's repository and diffs a tracked file against HEAD instead of showing it as new; an edit through a symlinked directory is diffed against its real path; a FIFO or an oversized file is never read.
- [fix] Open in tool resolves a relative path against the thread's folder, not the repository root.
- [fix] Finding a thread's repository for the diff panel and the external diff tool no longer runs git on the main thread.

### Settings and detection

- [fix] A directory or a non-executable file named like an agent's CLI no longer counts as installed, and the Enabled row can no longer say "Ready" beside "Not found".
- [fix] Settings no longer say "Synced" when Codex's rules cannot be read; the import button reads "Not Checked" with the reason.
- [fix] The Saved Permission Rules row no longer reads the rules file on the main thread; the differences dialog names why an unusable rules file cannot be used.
- [fix] The approval hook row names the reason when no approval socket can be bound.
- [fix] A non-UTF-8 environment variable no longer panics profile resolution.
- [fix] An account's quota windows are cleared when the account changes, not when its plan refreshes.
- [fix] Removing a workspace checks terminal tabs in every window, and a tab opened while a worker exits keeps its worktree.

## Testing

`make check` runs about 2,100 tests and 47 display tests. New regression tests cover declared capabilities, sibling tokens after a close, bypass wakes and worker approvals, the stream sanitiser (a property test over random cuts, closes, evictions and rollbacks: 18 of 200 seeds stored part of a token before the fix), each redaction shape, each grant and hook-proof bypass, the push target, the uninstall plan and its refusals, and the transcript's row budget. `packaging/smoke-install.sh` now runs `agent-terminal --uninstall --yes` after installing each package and checks that the data and the package are gone.

## Upgrade and install

Settings, threads and approval rules are retained, and the store is not migrated. Download the appropriate package and `SHA256SUMS` from this release, verify the checksum (and, optionally, the provenance with `gh attestation verify <file> --repo jean1880/agent-terminal`), then install it:

| Distribution | Command |
|---|---|
| Debian 13, Ubuntu 24.04 or newer | `sudo apt install ./agent-terminal_3.7.0-1_amd64.deb` |
| Fedora 40 or newer | `sudo dnf install ./agent-terminal-3.7.0-1.x86_64.rpm` |
| Arch Linux | `sudo pacman -U ./agent-terminal-3.7.0-1-x86_64.pkg.tar.zst` |

To remove it later, run `agent-terminal --uninstall`.

## Known limitations

- A hook file created, or a plugin symlink retargeted, after agy's hook proof and before agy reads its hooks is not seen by the proof. The canary bounds it to one unasked step.
- A hook connection still in the kernel's accept backlog when its agent exits is first seen afterwards.
- A Claude sub-agent continued by a new Claude process that never saw the first `Agent` call is shown as before, as a background task.
- The redactor does not catch names with no sensitive part, values under 8 characters, multi-line values, or credential programs other than curl, wget, mysql, mariadb, mysqldump and sshpass.
- The 3.5.0 delegation limits still apply: Codex as a sub-agent starts its own workers outside Agent Terminal's limits, agy children need the managed bridge, and closing the app ends every child.
