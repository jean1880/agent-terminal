Agent Terminal 3.4.0 makes Claude, Antigravity and Codex threads look and behave the same: one approval card whose buttons mean the same thing for every agent, one reasoning block, one tool-card grammar, and an approval rule engine that agent-terminal owns for all three agents and that fails closed.

## Before you upgrade

- **Approval rules are re-approved.** Rules now live in a new typed, versioned file (`approval-rules.json`). The old `always-allow.json` is ignored and left on disk; approve again what you still want.
- **Rules that 3.3.x wrote into a project's `.claude/settings.local.json` are no longer managed.** agent-terminal never writes Claude's settings for "Allow for session" or "Always allow" any more. Clear those entries by hand if you no longer want Claude to auto-approve them outside agent-terminal.

## Added

- **One approval card for every agent**: Allow once, Allow for session, Always allow, Deny and Stop turn. Deny lets the agent see the refusal and continue; Stop turn ends the turn. A refused card is styled red, never green.
- **App-owned approval rules**: agent-terminal records every session and always rule itself and answers matching requests for Claude, Antigravity and Codex from one list. Always rules carry the agent they were created on and match across agents by kind (a shell command, one file inside the workspace, or one MCP tool). Session rules end when you switch to another agent, and the switch notice says how many ended.
- **Reasoning block**: one collapsible block with four states (streaming, complete, replayed, not shared by this model). Claude streams summarised thinking on CLI versions that support it; Codex shows its reasoning summary.
- **One tool-card grammar**: `Read <path>`, `Search <pattern>`, `Run <command>`, `Edit <path>`, `Create <path>`, `Fetch <url>`, `<server>/<tool>`, with the raw request behind Details. Codex shell wrappers (`zsh -lc '…'`) are unwrapped.
- **Copy and Show full** on tool sections, diffs, approval details and errors.
- **`@` files for Antigravity and Codex** from the app's own index of the thread's folder (secret-looking paths are never listed).
- **Antigravity hook status** in Settings → Agents: Ready, Not installed, or Could not verify.
- **Permission sources** in Settings: an optional list of files that import and export read, replacing the built-in path.
- **Unsupported controls explain themselves**: `/help` lists what an agent lacks, and a command it cannot run (for example `/mcp` on Codex) says why instead of being sent as a prompt.

## Changed

- **The rule matcher fails closed.** A remembered command never auto-approves anything containing shell syntax (`;`, `&&`, `|`, `$(`, backticks, `$VAR`, redirection, globs, a leading `NAME=value`, non-ASCII whitespace, a leading `=`), and never covers options that run other code (`git -c`, `find -exec`/`-delete`, `cargo --config`, `rg --pre`, `tar -I`, …). Only a short list of read-only programs can be extended with a trailing `*`. Commands that run workspace code (build tools, test runners, interpreters, wrappers) and commands carrying credentials are never offered "Always allow".
- **Edits and reads are contained**: paths are canonicalised, and anything outside the workspace, through a symlink, or on a sensitive file (`.git`, `.env`, workflows, home dotfiles, agent instruction files such as `AGENTS.md` and `CLAUDE.md`) never auto-matches. Antigravity reads outside the workspace now ask in every mode, Plan included.
- **Codex Accept edits** auto-accepts edits inside the workspace while shell commands still ask.
- **Secrets are masked live**, in approval cards, tool cards, questions, notices and prompt snapshots, not only in the store.
- **Import** applies the same checks as the rule dialog: a rule that would run workspace code or carries a credential is skipped, and the toast says how many were skipped. Saving rules is serialised by a lock, so two quick answers no longer race.
- **Export** writes only global rules, escaped, and warns that exported grants live outside agent-terminal.
- **Credentials on the command line** (`curl -u`, `Authorization:` headers, `user:pass@` URLs, password options) are masked in what you see and never become a rule.
- **Compact, continue and fork keep the thread's mode** (and fork its model) instead of adopting the profile default.
- Toasts appear over the transcript and never cover the composer; the header hides its activity text at narrow widths.

## Fixed

- Labels inside buttons no longer swallow clicks (tool-card titles, Thought process, usage meter, question options, rule suggestions, sub-agent rows).
- Row titles containing `&` are no longer blank.
- A Claude permission request left unanswered is denied after 570 seconds, and a late answer keeps no rule.
- Codex "no rollout found" on reopening a thread now continues in a new Codex thread with the conversation carried over.
- The question card leaves "Sending…" once the answer is accepted.
- Codex approval cards show the command and working directory; ExitPlanMode renders its plan as markdown; long requests are capped behind Show raw.
- Antigravity interrupt no longer shows "Turn failed"; `/usage` for Antigravity is formatted.
- The welcome dialog's Get Started button stays inside the dialog at small sizes; Settings dropdowns no longer truncate their value.
- The Antigravity transcript is read off the main thread.

## Upgrade and install

Settings and threads are retained; approval rules are not (see above). Download the appropriate package and SHA256SUMS from this release, verify its checksum, then install it:

| Distribution | Command |
|---|---|
| Debian 13, Ubuntu 24.04 or newer | `sudo apt install ./agent-terminal_3.4.0-1_amd64.deb` |
| Fedora 40 or newer | `sudo dnf install ./agent-terminal-3.4.0-1.x86_64.rpm` |
| Arch Linux | `sudo pacman -U ./agent-terminal-3.4.0-1-x86_64.pkg.tar.zst` |
