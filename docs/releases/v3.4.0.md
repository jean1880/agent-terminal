Agent Terminal 3.4.0 lets you talk to Claude and Codex while they work, answer approvals from the keyboard, and keep track of what sub-agents did after they finish. It groups the diff panel by folder, keeps active threads in a section of their own, lets Allow for session on an edit cover its folder, and checks GitHub for new releases. It also fixes questions that kept waiting after the agent was stopped, and Antigravity notices that showed raw JSON.

## Before you upgrade

- **agent-terminal now checks for updates at startup.** A few seconds after the first window opens, it asks GitHub once for the latest release, off the main thread. It is the app's only outbound connection. Turn it off in Settings → Startup → "Check for Updates at Startup"; Check for Updates… in the window menu still works when you ask.

## Added

- [feat] **Messages sent mid-turn reach Claude and Codex at once.** Writing while a turn runs used to queue the message until the turn ended, for every agent. Claude and Codex both take input mid-turn, so the message now goes straight in and is shown as sent: Claude folds it into the running turn, and Codex receives it through `turn/steer`, pinned to that turn. If the turn ends first, it starts a turn of its own and a notice says so. Antigravity, slash commands, and a message waiting on a hand-off are still queued as before.
- [feat] **Keyboard answers for approvals.** While an approval is waiting in the focused thread: `Ctrl+Enter` allows, `Ctrl+Shift+Enter` allows for the session, `Ctrl+Alt+Enter` always allows, `Ctrl+Backspace` denies (or stops the turn where there is no Deny), and `Ctrl+.` stops the turn. A Codex permission request can only be denied or stopped from the keyboard, never allowed. A key the card does not offer does its usual job, so `Ctrl+Backspace` still deletes a word when nothing is waiting.
- [feat] **`Ctrl+Shift+A` opens every sub-agent card** in the thread, or closes them all when all are open. All six new shortcuts are in the Keyboard Shortcuts window.
- [feat] **Check for Updates…** in the window menu asks GitHub for the latest release. A newer one opens a dialog with its version, its release notes and a Download button for the release page, with a note that package-repository installs update there. Otherwise it says you are up to date, or what failed (unreachable, rate limited, no release yet). The request is a single HTTPS GET with a 15 s timeout and a 1 MiB reply cap, using a pure-Rust TLS stack (no new system library), and only GitHub links are opened.
- [feat] **Update check at startup**, on by default (see Before you upgrade). A newer release puts a yellow dot on the window menu button in every window and turns the entry into "Download Update X.Y.Z…", which opens the notes and Download at once. Being up to date, or a failed check, is only logged.
- [feat] **Active threads have a section of their own.** Threads that are working, waiting for an approval, rate limited or running background work sit at the top of the sidebar in an "Active" section, most urgent first (approval, rate limit, working, background; newest first within each), each naming its folder. A divider follows, then every other thread grouped by folder as before. A folder left empty disappears. Search and the archive toggle apply to both sections.
- [feat] **The diff panel groups files under their folder.** Each folder has a header (the repository root first), and each file is a collapsed row with its +/- counts and the Open in button. Expanding a row shows that file's diff alone, built when first opened, so a large change set lists at once. A file past where the diff was cut short, or in a diff too large to show, says so rather than showing another file's text.

## Changed

- [change] **Allow for session on an edit covers its folder.** An edit rule used to hold exactly one file, so every other file in the same crate asked again. The button now keeps the file's folder and everything below it, and the card says which folder before you click. It never reaches past the workspace, except at least two levels inside your home folder (never `~/git`, `~/bin`, `/tmp`, `/etc` or `/run`), and never covers `/` or your home folder itself. Sensitive files inside the folder still ask. Folder rules last for the session only: Always allow keeps exact files, and the rule dialog never prefills a folder.
- [change] **Finished sub-agents stay docked until your next prompt.** The workers card above the composer used to slide away the moment the last sub-agent finished. Each sub-agent now docks when it is seen running and stays after it ends, its row showing how it ended (completed, failed…) and the title counting both ("1 worker active · 2 finished"). Sending the next prompt or choosing "Clear finished" removes the finished ones; sub-agents replayed from history never dock.
- [change] **Supply-chain checks in CI.** Dependabot updates the Rust crates and GitHub Actions weekly, moving the gtk-rs crates together. CodeQL scans the Rust code and the workflows, cargo-deny enforces licences, advisories, bans and sources (`deny.toml`), dependency review blocks pull requests that add vulnerable crates, and Scorecard reports supply-chain posture. Every workflow action is pinned to a commit. `SECURITY.md` explains how to report a vulnerability privately.
- [change] **Dependencies updated**: rusqlite 0.32 → 0.40, and 48 minor and patch updates, including gtk4 0.11.5, glib and gio 0.22.10, libc 0.2.190, serde 1.0.229 and serde_json 1.0.151.
- [change] The README shows the app icon above the title.

## Fixed

- [fix] **A question stops waiting once the agent stops or drops it.** Stopping the agent while it asked a question left the question unanswered for good, still pinned above the composer. A question Claude drops (on a stop, or when its process ends) is now withdrawn, one that expires is marked expired, and a stopped turn expires every approval, question and form still waiting. A turn that completes or fails leaves them alone, because Codex workers and Claude background sub-agents can outlive it and still ask.
- [fix] **Antigravity's denied actions are named.** The notice used to print raw JSON (`Denied actions: {"action":"command","display_name":"RunCommand"}, …`); it now reads "agy denied these actions: RunCommand (command), ViewFile (read_file)". An unexpected Antigravity exit right after a turn with denials adds a notice naming them, and says that sending a message resumes the conversation.
- [fix] **Sub-agent spinners stop when the sub-agent finishes**, even while the workers card is collapsed.

## Upgrade and install

Settings, threads and approval rules are retained. Download the appropriate package and SHA256SUMS from this release, verify its checksum, then install it:

| Distribution | Command |
|---|---|
| Debian 13, Ubuntu 24.04 or newer | `sudo apt install ./agent-terminal_3.4.0-1_amd64.deb` |
| Fedora 40 or newer | `sudo dnf install ./agent-terminal-3.4.0-1.x86_64.rpm` |
| Arch Linux | `sudo pacman -U ./agent-terminal-3.4.0-1-x86_64.pkg.tar.zst` |
