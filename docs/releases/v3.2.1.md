Agent Terminal 3.2.1 delivers strictly one-way permission synchronisation, non-intrusive permission discrepancy warnings in the settings menu, and removal of automatic background sync.

## Added

- **Strictly one-way permission synchronisation**:
  - Dedicated, explicit "Import Now" and "Export Now" actions in Settings → Agents → In-App Approvals & Pattern Matching.
  - One-way import pulls allowlisted commands and tools from Claude Code, Antigravity, and `permissions.toml` into Agent Terminal's `always-allow.json` without modifying external files.
  - One-way export pushes Agent Terminal's remembered pattern rules out to `permissions.toml`, Claude `settings.json`, and Antigravity `settings.json` without modifying internal rules.
- **Permission sync discrepancy warnings in Settings**:
  - The In-App Approvals & Pattern Matching menu detects when saved rules differ from external agent configurations.
  - Displays a dedicated warning row with a warning indicator above the import and export controls detailing unimported and unexported rule counts.
  - Contextually highlights import and export controls when unimported or unexported rules exist and updates live upon synchronisation.
  - The "Manage Rules…" dialogue subtitle also alerts operators to synchronisation divergence.

## Changed

- **Removed automatic background permission sync**:
  - Removed silent automatic import of external agent permissions on empty rule sets, ensuring rule synchronisation remains strictly intentional and operator-directed.

## Upgrade and install

Existing settings and threads are retained. Download the appropriate package and SHA256SUMS from this release, verify its checksum, then install it:

| Distribution | Command |
|---|---|
| Debian 13, Ubuntu 24.04 or newer | `sudo apt install ./agent-terminal_3.2.1-1_amd64.deb` |
| Fedora 40 or newer | `sudo dnf install ./agent-terminal-3.2.1-1.x86_64.rpm` |
| Arch Linux | `sudo pacman -U ./agent-terminal-3.2.1-1-x86_64.pkg.tar.zst` |
