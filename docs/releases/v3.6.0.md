Agent Terminal 3.6.0 makes delegation feel like one team: a thread now counts every agent it spins out (delegated workers, Codex's own workers, and agents launched from a shell command) as its sub-agents, and an idle parent wakes up with their results instead of waiting to be asked. Parents choose a child's model and effort from built-in model tags and each agent's remaining usage. Switching agents now happens in place, the model picker says what a switch costs before you make it, and the first-start setup explains every change it makes. The interface gains restrained motion, agent-aware activity dots that stay legible on a light desktop, and visible progress for pushes, update checks, undo and MCP reconnects. Every published package now carries a signed build provenance attestation.

## Before you upgrade

- **No store migration.** The thread store stays at schema 5, so 3.5.0 and 3.6.0 can open the same database.
- **Automatic Pattern Approvals now applies to every agent.** With the switch off (Settings → Agents; it is on by default), saved **Always allow** rules no longer approve matching requests for Claude, Codex or agy, cards no longer offer Always allow, and an Always answer on a card already showing allows that one call and keeps nothing. Your saved rules stay in the file. If you turned the switch off in an earlier release, expect more approval cards than before.
- **Sessions started outside the app are listed, with a toast.** Recent Claude, Codex and agy sessions started in a terminal or by another tool appear in the sidebar, and a toast says how many were added. Turn it off in Settings → Behaviour → "Show Sessions Started Outside Agent Terminal".
- **A delegation root may start turns by itself.** When a sub-agent finishes, fails or reports, an idle parent thread starts a turn with the news (see Added). Stopping the parent holds this until you speak again.

## Added

### Sub-agents and delegation

- [feat] **An idle parent hears from its sub-agents.** When a delegated child finishes, fails or sends its parent a message, the parent's thread gets a notice and, if idle, starts a turn with the news. The news is redacted before it is cut to the hand-off budget, children finishing together are coalesced into one turn, and a busy parent gets it once its turn ends. News the parent already saw through `cross_agent_wait` or `cross_agent_read` is not sent again. After 20 consecutive wakes without you, the parent gets a notice instead of a turn, and a parent you stopped is not woken until you speak.
- [feat] **Every agent a thread spins out is its sub-agent.** Delegated workers and Codex's own workers count as the thread's background work: in the sidebar badge, the close question, the held finish and idle suspension. A parent whose turn is over while a delegated worker runs waits on it rather than reading as completed. A sub-agent's approval or question badges, notifies and marks its root thread as the root's own would, and is withdrawn once answered or ended.
- [feat] **Agents launched from a shell command are recognised.** A command card that runs `cross-agent`, `claude -p`, `codex exec` or `agy -p` (through wrappers, chains and nested shells) is listed with the thread's sub-agents under the agent it launched, lights that agent's dot while it runs, and shows its prompt and output in the sub-agent panel. A delegated child that tries to launch one is refused as a nested sub-agent, so the depth limit cannot be stepped around through the shell.
- [feat] **Capabilities help a parent choose.** `cross_agent_capabilities` now lists every ready agent's models with tags, tier, what each is best for, and the effort to use for fast, standard and deep work, plus each profile's usage headroom (ok, low, exhausted or unknown) and load, never an account. `refresh: true` re-reads usage first, at most once a minute per agent. The same usage, without account fields, is written to `$XDG_CACHE_HOME/agent-terminal/usage.json` (`0600`, atomic) for tools outside the app.
- [feat] **Built-in model tags.** Every install now ships tags, tiers and an effort policy for each agent's model families, matched by name. A `model-tags.json` in the config folder (or at `model_tags_path`) is laid over them rather than being the only source, and a file that cannot be read falls back to the built-in tags with its reason.
- [feat] **Root threads are told about the other agents.** A delegation root Claude gets a short appended system prompt, and a root Codex the same note as developer instructions (after your own `developer_instructions`), naming the other agents as sub-agents and the tools that reach them, so they are considered before the built-in sub-agents. The capabilities tool's description says the same for agents that read tool descriptions up front, such as agy.
- [feat] **Live-following output.** The sub-agent dialog (delegated workers included) and a background task's output dialog open at the end and follow new output until you scroll up; scrolling back to the end follows again. New task output is appended, so a reader who scrolled up keeps their place.
- [feat] **The thinking strip lights every agent at work**, including each agent a running sub-agent is on, beside the thread's own.

### Threads and chat

- [feat] **Agent lifecycle is visible.** The header shows "Starting…" while the agent spawns, "Resuming…" when a message wakes a paused agent, and "Paused: resumes when you send" while it is paused. The sidebar row spins while starting and carries a "Paused" badge.
- [feat] **Reopen your last session.** With Reopen Last Thread off, the empty window offers "Reopen N threads from your last session".
- [feat] **Model and effort choices are clear.** The picker says how a choice is made, and changing the effort on a row shows an Apply button. The model chip names the effort (`Claude · opus · high`) unless the model id already carries it.
- [feat] **A switch's cost is shown before you make it.** The picker's group for another agent lists what switching costs: the summary hand-off, session approvals that end, dangerous permissive mode ending, and an Antigravity whose approval hook is not ready. Mid-turn, a model change on the same agent asks "Change Model Now?"; picking what the thread already runs closes the picker with no interrupt.
- [feat] **The switch reads in the right place.** The agent-switch divider is drawn on the new agent's first event, so the switch's own notices read under it, and the continuation prompt a switch sends is a centred marker (its text in the tooltip) that is left out of the composer's recall history.

### Setup and approvals

- [feat] **First start explains itself.** The setup's **Your Agents** page names who is ready (installed and signed in), shows each agent's install and sign-in state with **Get It**, **Check Again** and **Sign In…**, whether Antigravity's approval hook is installed (with an entry to **Copy**: setup never edits agy's files), the default agent for new threads, Automatic Pattern Approvals, and the startup update check. Every switch applies at once. On a first start the update check waits until setup closes. Setup writes only Agent Terminal's own settings file.

### Look and feel

- [feat] **Agent-aware dots.** The thinking strip's three dots (the app icon's, one per agent) light the agent at work and dim the other two. A new thread's empty transcript shows them at rest with its agent lit, and picking another agent fades the light across.
- [feat] **Legible on a light desktop.** On a light desktop theme the agents' colours are darkened just enough to keep 3:1 contrast against white, and swap back when the desktop turns dark.
- [feat] **Restrained motion.** Buttons, cards, the composer and panel rows ease colour, border, opacity and shadow over 150 ms. Your message and the first row of the reply fade in (180 ms, opacity only); a fast stream does not. A switch's divider settles into place in the new agent's colours. A model or mode switch waiting for its turn pulses on the chip. The Resume Session dialog, a terminal's loading screen and the diff panel's pages crossfade. Everything stops when the desktop turns animations off, and replayed history never animates.
- [feat] **A loading usage reading shows its agent's droplet.** While a probe fetches an agent's usage, the indicator says "Checking…" beside an animated droplet in the agent's colour instead of "Unknown". Older data stays shown, muted, while it refreshes.
- [feat] **Feedback while things run.** Push & Open PR turns into a "Pushing…" spinner until the push ends, then a toast names the pushed branch. Check for Updates and Undo Changes show a toast while they work. An MCP reconnect shows a spinner and "reconnecting…" for at least 700 ms, then a toast with the outcome.
- [feat] **The Changes toggle appears only where there is something to diff.** Outside a git repository it is hidden, and Ctrl+Shift+D and its menu entry are disabled; it comes back when a repository appears. It now uses a git icon, and Settings uses Adwaita's gear.

### Project

- [feat] A Code of Conduct (Contributor Covenant 3.0), a contributing guide, issue forms for bugs and features, and a pull request template. Security problems are reported through GitHub's private vulnerability reporting (see `SECURITY.md`).
- [feat] **Signed build provenance.** Every package in a release, listed in `SHA256SUMS`, carries a provenance attestation tying it to the workflow run, commit and tag that built it. Check it with `gh attestation verify <file> --repo jean1880/agent-terminal`. Releases are immutable once published.

## Changed

- [change] **Switching agents keeps the thread.** A switch now changes the agent in place, including for a thread that is unopened, still starting or whose custom command failed. The provider change and the redacted hand-off are stored together, and startup waits for that record before choosing the agent. Menus distinguish switching in place from continuing in a new thread.
- [change] **Forks and compacts keep your choices.** A fork keeps the selected model, effort and safe mode. Compacting offers an explicit action to archive the original, which Undo reverses.
- [change] **A thread keeps the profile it was opened with**, as long as that profile still runs the thread's agent; otherwise it falls back to the agent's own profile rather than starting the wrong CLI.
- [change] An agy child's effort is now carried in its model id (for example `gemini-4-argon-high`); before, the requested effort was silently dropped.
- [change] The usage meter keeps its height while loading.
- [change] Delegation logs spawns, state changes, stalls, failed dispatches, cancels, closes and lost bridges to the journal.
- [change] `rustls-webpki` 0.103.16 and `webpki-roots` 1.0.10 (RUSTSEC-2026-0381, RUSTSEC-2026-0382: distrust of the compromised emSign intermediates, reached through the update check). Patch updates to `deranged`, `equivalent`, `litrs`, `syn` and `unicode-ident`.

## Fixed

### Threads

- [fix] An unsent message is no longer lost silently: the app asks first. A discarded blank thread is recreated with its saved settings, and an archived thread comes back through Undo. Archive and delete report their outcome only once the store confirms it.
- [fix] A new thread keeps its selected profile, folder, worktree and hand-off through creation and reopening, and inherited settings are acknowledged only once saved.
- [fix] Opening a thread whose agent was not yet prepared no longer floods the window with "registry was unavailable" toasts; its workers are listed before their history is replayed, and an overflow is reported once.
- [fix] Readiness is shown only after the agent's handshake, stale session imports are cancelled, and lifecycle hints stay visible in narrow headers.
- [fix] Deleting a root thread removes its sub-agents' per-thread settings with their hidden threads, and resuming a child's native session is refused rather than making a visible duplicate.

### Delegation

- [fix] An agy child is handed its task only once its process exists; before, the task was refused while the hook was still being proven and the worker stayed "starting" for ever. A start that never comes fails the worker after the startup deadline.
- [fix] A task whose turn does not open within 60 seconds is reported as a stall, with the reason.
- [fix] A run cancelled before delivery is saved as interrupted (reason "cancelled") and the worker stays waiting, rather than failing it or revoking its authority twice. Stall and cancel handling apply only to their own run.
- [fix] A dispatch that fails before reaching the agent ends the run it reserved, in memory and in the store. `cross_agent_list` reads each worker's run from the store, so a listed `run_id` is one `cross_agent_cancel` accepts.
- [fix] A lost bridge connection records that it must be rebound, with a reason, and an agy bridge no longer presents its spent single-use capability on reconnect.
- [fix] A cursor reused with another filter is refused, naming the filter it was issued for, and a refused read no longer uses up its idempotency key.
- [fix] Quitting commits each root's delegation revocation before the store writer closes (waiting at most 3 seconds), instead of leaving it to crash recovery at the next start.
- [fix] A child's approval socket is bound in the supervisor's verified runtime folder and the child's own home, not ambient `XDG_RUNTIME_DIR` and `HOME`.
- [fix] A switch asks before it stops delegated sub-agents' work, and a thread's notification and its sub-agents' open questions survive the root's own answers and a restart of its process.

### Approvals

- [fix] An Always answer given while Automatic Pattern Approvals is off allows once and keeps nothing, with a notice; the switch is read again right before any rule is saved, and stays in step across windows.
- [fix] A read's rule dialog is prefilled with its path, not the card's note.

### Setup, panels and look

- [fix] Setup holds the startup update check for the whole first run, releases it through its own dialog, and calls an agent ready only once it is signed in.
- [fix] Escape closes the model picker and the Resume Session dialog.
- [fix] The Changes toggle's holder hides with its button at narrow widths, so a 360 px window fits.
- [fix] The loading droplet no longer logs a GTK assertion for an empty CSS class.
- [fix] A diff refresh during a push keeps the PR button busy, so a second push cannot start.
- [fix] The row after a queued message no longer fades in as though it answered it.

## Testing

New regression tests cover report-keyed wakes, news after a stop, refused wake sends, cancel-before-delivery, model tags, switch caveats, the stylesheet's motion rules (no transitioned size or spacing, which would relayout the transcript every frame) and the light-desktop contrast of the agents' colours. CI cancels a pull request's superseded runs, empties the test home before every run, and on a failure of `test_window_initialization` records the runner's CPU and renderer and a `gdb` backtrace (`make test-gdb T=<name>`).

## Upgrade and install

Settings, threads and approval rules are retained, and the store is not migrated. Download the appropriate package and `SHA256SUMS` from this release, verify the checksum (and, optionally, the provenance with `gh attestation verify`), then install it:

| Distribution | Command |
|---|---|
| Debian 13, Ubuntu 24.04 or newer | `sudo apt install ./agent-terminal_3.6.0-1_amd64.deb` |
| Fedora 40 or newer | `sudo dnf install ./agent-terminal-3.6.0-1.x86_64.rpm` |
| Arch Linux | `sudo pacman -U ./agent-terminal-3.6.0-1-x86_64.pkg.tar.zst` |

## Known limitations

- Recognising an agent launched from a shell command is a reading aid: a command it cannot parse runs as an ordinary command card, and only a delegated child's launches are refused.
- The 3.5.0 limitations on delegation still apply: Codex as a sub-agent starts its own built-in workers outside Agent Terminal's limits (now counted as the thread's work, but still unsupervised), agy children need the managed bridge, and closing the app ends every child.
