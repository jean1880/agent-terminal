Agent Terminal 3.1.1 introduces interactive in-app pattern auto-approval management, cross-agent permission rule importing, session-scoped rule loosening, and GLib thread-dispatch hardening.

## Added

- **In-app pattern auto-approval and rule loosening**:
  - **Pattern engine**: Linear wildcard matching (`*`, `?`) for shell commands and MCP tools in `.agent-terminal/always_allow.toml`.
  - **Interactive rule loosening**: When approving commands, operators can modify proposed patterns with preset chips (`cargo *`, `make *`, `npm *`) or custom globs rather than repeatedly approving individual tool invocations.
  - **Session-scoped permissions**: An explicit "Save for Session" option allows approving commands and tools for the duration of the current session without persisting them to disk permanently.
  - **Cross-agent rule importing**: Import existing execution permissions directly from Claude Code (`allowedTools`) and OpenAI Codex (`project.toml`) into Agent Terminal.
  - **Codex auto-approval parity**: Codex commands matching active session or persistent rules are automatically approved without operator interruption.

## Fixed

- **GLib thread-default context dispatch**: Auto-approval resolution events are dispatched through the thread-default `MainContext`, preventing thread guard violations during asynchronous idle iterations.

## Upgrade and install

Existing settings and threads are retained. Download the appropriate package and SHA256SUMS from this release, verify its checksum, then install it:

| Distribution | Command |
|---|---|
| Debian 13, Ubuntu 24.04 or newer | `sudo apt install ./agent-terminal_3.1.1-1_amd64.deb` |
| Fedora 40 or newer | `sudo dnf install ./agent-terminal-3.1.1-1.x86_64.rpm` |
| Arch Linux | `sudo pacman -U ./agent-terminal-3.1.1-1-x86_64.pkg.tar.zst` |
