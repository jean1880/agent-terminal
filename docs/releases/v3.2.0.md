Agent Terminal 3.2.0 delivers per-agent default model configuration, theme-consistent approval suggestion buttons, selectable transcript text, transparent action-oriented card headers, and hardened git diff resolution.

## Added

- **Per-agent default model configuration**:
  - The default model for each agent is now configured and pulled directly from the agent's settings, ensuring new threads open with the intended model tier.
- **Theme-styled approval suggestion buttons**:
  - Suggested permission rules in approval popups are now presented as selectable option buttons styled in harmony with the questions panel.
- **Selectable transcript text**:
  - All labels across user bubbles, assistant markdown, reasoning rows, tool cards, notices, dividers, and approval requests are now selectable, allowing any text in the chat to be highlighted and copied.

## Changed

- **Transparent chat card titles and headers**:
  - Card headers now display distinct action verbs (**Read**, **Edit**, **Write**, **List**, **Search**, **Find**, **Run**, **Fetch**, **Subagent**) alongside target paths, queries, or commands, eliminating ambiguous bare filenames.
  - Expanding cards displays clean, formatted properties (action description, search pattern, directory path, file target, line ranges, URL, or subagent role) rather than raw JSON payloads.

## Fixed

- **Git diff resolution & "Show changes"**:
  - Edit cards without embedded diff hunks now resolve target files against pre-turn git checkpoints (`TurnBase`), falling back to repository `HEAD` when recovering across restarts.
  - External diff tool launching now accurately resolves modified file paths across Claude, Antigravity, and Codex tools.
- **Approval hook signal interruption handling**:
  - Intercepted termination signals (`SIGTERM`, `SIGINT`, `SIGHUP`) in `agent-terminal --approval-hook` to ensure sudden runner restarts or cancellations exit with a structured denial payload instead of an unhandled signal crash.

## Upgrade and install

Existing settings and threads are retained. Download the appropriate package and SHA256SUMS from this release, verify its checksum, then install it:

| Distribution | Command |
|---|---|
| Debian 13, Ubuntu 24.04 or newer | `sudo apt install ./agent-terminal_3.2.0-1_amd64.deb` |
| Fedora 40 or newer | `sudo dnf install ./agent-terminal-3.2.0-1.x86_64.rpm` |
| Arch Linux | `sudo pacman -U ./agent-terminal-3.2.0-1-x86_64.pkg.tar.zst` |
