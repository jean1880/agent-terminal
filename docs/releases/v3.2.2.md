Agent Terminal 3.2.2 isolates filediff unit testing to hermetic in-memory fixtures and cleans up the release bump automation.

## Changed

- Replaced the integration-style filediff test with an isolated in-memory unit test that exercises `shown_for_item` without invoking host `git` commands.
- Extracted Makefile version bump recipe into an executable `packaging/bump-version.py` helper script for reliable release maintenance.

## Fixed

- Remedied Arch Linux packaging failure where `cargo test` attempted to execute `git` in minimal build environments.
- Corrected syntax error during Makefile version bumping across multi-line shell recipes.

## Upgrade and install

Existing settings and threads are retained. Download the appropriate package and SHA256SUMS from this release, verify its checksum, then install it:

| Distribution | Command |
|---|---|
| Debian 13, Ubuntu 24.04 or newer | `sudo apt install ./agent-terminal_3.2.2-1_amd64.deb` |
| Fedora 40 or newer | `sudo dnf install ./agent-terminal-3.2.2-1.x86_64.rpm` |
| Arch Linux | `sudo pacman -U ./agent-terminal-3.2.2-1-x86_64.pkg.tar.zst` |
