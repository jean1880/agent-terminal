Agent Terminal 3.1.0 delivers major agent feature parity across Claude, Antigravity, and Codex, with enhanced thinking telemetry, multi-agent workspace reviews, and persistent permissions.

## Added

- **Agent feature parity across all three engines**:
  - **Antigravity Plan Mode notice**: Displays an informative banner when Antigravity starts in `Mode::Plan`, making it clear that edits are withheld until approval hooks are active.
  - **Codex persistent permissions**: Command execution approvals in Codex now offer "Always allow", storing prefix rules to `.agent-terminal/always_allow.toml` with workspace-scoped auto-approval on subsequent turns.
  - **Antigravity context window inspection**: Antigravity tracks cumulative tokens across turns and answers the `/context` command and Context Window inspection panel dialog (`Control::ContextUsage`).
  - **Codex transcript history import**: Native Codex CLI session logs can now be imported directly into Agent Terminal chat threads, balancing items, tool calls, and user messages.
  - **Live thinking ticker**: A live elapsed second timer updates the thinking strip in real time while an agent is thinking or managing active background tasks.
- **Multi-agent environment reviews**: Review and verify environment configurations across agents with interactive dialog confirmations.
- **Keyboard shortcuts**: Quick keyboard shortcuts for navigating between threads, opening session controls, and handling approvals.
- **Attention indicators**: Collapsed sidebar attention indicators highlight threads requiring approval or human input.

## Changed

- **Process isolation**: Agent processes cleanly drop inherited approval socket environment variables when launched without active approval handles, preventing unexpected socket leakage.
- **Viewport handling**: Long tool execution titles are bounded within the transcript viewport, preventing horizontal blowout on extensive command lines.
- **Model switching during active turns**: Enforces active model switches and seamlessly continues interrupted work across agent hand-offs.

## Fixed

- **Codex approval reconnection**: Preserves pending approval state across server reconnects, preventing lost or hanging requests.
- **Accessibility relations**: Retains accessible label and error relationships on older GTK runtimes.
- **Review cancellation handling**: Correctly handles dialog cancellation flows during workspace reviews.

## Upgrade and install

Existing settings and threads are retained. Download the appropriate package and SHA256SUMS from this release, verify its checksum, then install it:

| Distribution | Command |
|---|---|
| Debian 13, Ubuntu 24.04 or newer | `sudo apt install ./agent-terminal_3.1.0-1_amd64.deb` |
| Fedora 40 or newer | `sudo dnf install ./agent-terminal-3.1.0-1.x86_64.rpm` |
| Arch Linux | `sudo pacman -U ./agent-terminal-3.1.0-1-x86_64.pkg.tar.zst` |

## Known limitations

- Antigravity structured question polyfill and MCP server multiplexing are documented in the Cut 4 architectural plan and scheduled for a dedicated subsequent release.
- A permission-mode change during an active Codex turn takes effect on the next turn; current-turn approval requests still require a response.
