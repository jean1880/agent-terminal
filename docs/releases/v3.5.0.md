# Agent Terminal 3.5.0

Supervised delegation gives coding agents a common way to pass work between
providers, with child activity and controls in the existing worker inspector.

## Added

- Eight delegation tools in the existing `agent-terminal --cross-agent-mcp`
  executable. Each enabled thread receives its own authenticated local binding.
- Child transcripts, messages, approvals and diffs in the worker dock, with
  provider branding and explicit model/effort provenance.
- Isolated git worktrees for writing children, inherited authority checks,
  bounded child trees and process limits, durable receipts and mailbox delivery.
- Profile opt-in and managed agy registration with a selected-environment test,
  repair, removal and postimage-checked undo.
- Installed-provider proof fixtures and no-display MCP checks in the Debian,
  Fedora and Arch packaging pipeline.

## Changed

- Store schema 5 records worker/run relationships and each linked event's process
  generation. Upgrades use the existing verified backup and migration path.
- Stop, Close, restrictions and profile changes revoke supervised work. Window
  transfers restart the root with fresh credentials. Unfinished work after an
  app restart remains uncertain and is never automatically replayed.

## Fixed

- Delegated permission responses recheck current authority after asynchronous
  work and reject stale worker/generation cards.
- agy children require fresh approval-hook proof in their actual workspace;
  hookless fallback cannot launch a delegated child.
- Child publication shares the redaction boundary used for persisted and injected
  content, including protected launch metadata.
- Child activity is published after its store commit; terminal results and mailbox
  notifications commit together. Stale receipts cannot finish a replacement run.
- agy launch checks use the final process's working directory and environment
  facts, and later checks retain that generation's facts rather than a changed
  profile. Cancelled startup checks cannot spawn or send held input.
- Concurrent first opens inspect the store version and contents in one snapshot,
  preserving refusal of genuinely unrecognised databases.

## Upgrade and limitations

Update through your package manager, then enable profiles in Settings → Agents.
For agy, review and apply its managed registration. Existing profiles remain opted
out. See the [delegation guide](../delegation/user-guide.md) for setup and rollback.

Codex 0.161.0 can be a parent but cannot be a supervised child: its native worker
tool still executes despite disable settings. Unsupported routes report this
blocker. agy uses its verified bridge registration; this release has no automatic
fallback to an agy child without a bridge. Delivery timing and acknowledgement
differ by provider and are exposed in capabilities. The GUI owns supervised
processes; there is no detached daemon.

Keep the pre-migration database backup. An older binary must not open the migrated
schema in place. This release does not replace the separate homelab `cross-agent`
command or install external runtime services.
