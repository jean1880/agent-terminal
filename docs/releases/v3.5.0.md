Agent Terminal 3.5.0 lets every agent use every other as a supervised sub-agent: Claude, Codex and Antigravity can hand work to one another, and each child's transcript, approvals and diffs show in the worker dock. It adds GitHub pull requests from the diff panel, a diff panel that pops out into its own window, and approval cards that explain git and gh commands. A thread left idle out of sight now pauses its agent, so a busy window stops costing gigabytes of memory. The store writes off the main thread, and this release fixes more than forty bugs found in a review on 13 October.

3.4.1 shipped only dependency updates, so these notes cover everything since 3.4.0.

## Before you upgrade

- **The thread store moves to schema 5.** On first start, 3.5.0 makes a verified backup of the database (`backups/` beside it, `0600` in a `0700` folder) before it migrates, and records where in the store. Keep that backup: an older build cannot open the migrated store, and must never be pointed at it in place. To go back to 3.4.x, restore the backup first.
- **Idle agents pause after 15 minutes.** A thread out of sight with no activity for 15 minutes has its agent process stopped, but only when nothing would be lost (see Changed). The next prompt resumes the same conversation. Change or turn it off (0) in Settings → Behaviour → "Pause Idle Agents After (Minutes)".
- **Blank threads are discarded.** An untitled thread nobody wrote in is deleted when you switch away from it or close it, rather than staying in the sidebar as "New thread".
- **Delegation is off until you turn it on.** Existing profiles stay opted out. See the [delegation guide](../delegation/user-guide.md).

## Added

### Agents delegating to agents

- [feat] **Every agent can use every other as a sub-agent.** A thread's agent (Claude, Codex or Antigravity) can start, message, wait on and stop children running any other enabled agent, through eight tools served by the existing executable (`agent-terminal --cross-agent-mcp`): `cross_agent_capabilities`, `cross_agent_spawn`, `cross_agent_send`, `cross_agent_read`, `cross_agent_wait`, `cross_agent_list`, `cross_agent_cancel` and `cross_agent_close`. Each thread stays isolated: its own process, its own children and its own authenticated local binding, minted per process generation and never passed in argv. Switching a thread's agent keeps delegation, and two threads delegating at once never share a child.
- [feat] **Children in the worker dock.** Supervised children appear beside native sub-agents. Selecting one shows its activity, transcript, messages, approvals and file changes, with provider branding. The requested model, the reported model and the effort are each shown with where they came from, and anything the provider did not report stays "unknown".
- [feat] **Children never get more authority than their parent.** A child's mode is capped by its parent's live mode, and every child approval is judged against what the parent may do. A writing child works in its own git worktree (an `agent-terminal/<worker>` branch from a committed base), proven before use and never removed unless clean. A worktree that fails its proof is kept, not deleted, and reported as retained work. Edits are never merged back automatically.
- [feat] **Durable, recoverable runs.** Spawns, messages and completions are written to the store before they are acted on, with idempotency keys, receipts and a mailbox per recipient. After an abnormal restart, unfinished work is marked uncertain and never replayed. Depth, child count, process and output limits bound every delegation tree.
- [feat] **One switch in Settings → Agents.** "Agents can use each other as sub-agents" turns delegation on or off for every enabled agent. The per-agent "Available for delegation" switches stay as opt-outs, and a mixed state reads "Custom: on for …; off for …".
- [feat] **Managed Antigravity registration.** Turning delegation on for agy opens a review that lists, as a Target | Change table, every file and folder it would write or repair. Apply sets it up (tightening group- or world-writable paths through `O_NOFOLLOW` descriptors, and refusing any path that changed since the preview); Cancel leaves the switch off. **Test**, **Remove** and **Undo** are in the delegation settings. Undo restores only if the files still match what it recorded. The registration row checks itself whenever Settings opens and names any path it refuses.
- [feat] **Changing a busy thread's agent asks first.** If the thread is working, waiting on you or has sub-agents alive, Stop and Switch interrupts the turn and ends that thread's children only. Cancel changes nothing. A model change on the same agent never asks.

### GitHub and the diff panel

- [feat] **Open a PR from the diff panel.** A bar at the foot of the panel opens GitHub's compare page for the thread's branch in your browser. Credentials are dropped from the remote URL, and the app itself makes no request. A branch not fully pushed offers "Push & Open PR": one unforced `git push`, run through your own git and credentials after a confirmation that shows the command. Not a repository, another host, and an unreadable branch each have their own state.
- [feat] **The diff panel pops out into its own window**, titled after the thread, and docks back when that window closes, its page leaves, or its parent window goes.
- [feat] **Approval cards read git and gh commands.** A card says what the command does and how far it reaches (read-only, this repository, the remote), with its details (message, branch, remote, PR title). It warns about anything that loses work or rewrites history, and then Allow is no longer the suggested button. The command line is still shown beneath. Quoted heredoc commit messages and one plain shell wrapper are understood.
- [feat] **A thread's subtitle shows its branch** when the repository is on GitHub.

### Chat and sidebar

- [feat] **Dangerous permissive mode** approves every request for the current session only. Choosing it (from the mode picker or `/mode dangerous`) always shows a warning first, and Cancel changes nothing. It is never stored as the thread's mode, a fork or hand-off gets the last safe mode, switching agents ends it, and Settings never offers it as a default. For Claude it is `bypassPermissions`, for Codex `never` with `dangerFullAccess`, and for agy its approval hook allows everything. Hookless agy refuses it. A Codex permissions request is granted exactly as its card would show it, for that turn only.
- [feat] **Explore background tasks.** The thinking strip's **Show tasks** lists every background task (sub-agents and shell commands). A sub-agent opens in the sub-agent panel. A Claude shell task opens a dialog that follows its output (the last 8 KiB, read once a second until it ends), with escape sequences stripped and truncation flagged.
- [feat] **Collapsible folder groups.** Folder groups in the sidebar start collapsed. Click a header to expand or collapse it; a collapsed header counts what it hides. A search expands every group, the thread on screen stays listed under its collapsed folder, and each header has a **+** that starts a new thread in that folder.
- [feat] **Pick the repository in the New Worktree dialog.** It starts at the current thread's repository, and **Choose…** picks any folder in another repository, so no thread has to be open there first.
- [feat] **Model picker freshness.** The picker's footer reads "Updated N ago", "Refreshing…" or "Could not refresh; showing list from …", with a Refresh button.

## Changed

### Performance

- [perf] **Idle agents are paused, never ended.** Measured before this change: ten open Claude threads kept ten processes of about 270–360 MB each, plus their MCP helpers. A thread out of sight and quiet for `idle_suspend_minutes` (default 15) now has its agent stopped silently: no exit reaches the transcript or the store, and the next prompt resumes the same native session. A thread is never paused with a turn running, queued or in-flight input, an approval, permission card or question waiting, a model change or hand-off in progress, Codex session grants, a Codex thread that cannot be resumed, no conversation yet, dangerous permissive mode on, background work, or live sub-agents. While paused, a mode or model picked for the same agent is kept for the resume.
- [perf] **Open threads cost nothing while out of sight.** A profile of the live app showed resizing spent 74% of the main thread restyling every open thread, and an idle window walked every style node each frame. Only the selected page is now visible to GTK, unshown pages keep their loading skeleton still, and the transcript's frame tick runs only while mapped. Focus changes with eight threads open went from 35 ms to 16 ms a frame.
- [perf] **The store writes on its own thread.** Every write from the window and chat sessions (events, prompts, read marks, models, new and resumed threads) is queued to one writer thread that batches them in a transaction, checkpoints the WAL itself, and drains on shutdown. Reads that need their own writes wait on the writer's barrier, and are refused rather than made stale if it does not answer. The queue is bounded and failed or refused writes are counted and shown. Closing a window waits, with "Saving threads…" shown, until its writes are saved or you pick Quit Now (the default after 10 s, without moving focus to it).
- [perf] **Reopened threads show at once.** A thread opens with its newest 30 rows and fills in the rest of its window in idle steps of about 6 ms. On real threads of 42–47 thousand events, building the whole window used to be 70–80% of the 36–64 ms an open held the main thread. Jumping to a pending approval that is not built yet builds it first and lands on it.
- [perf] **The sidebar redraws only what changed.** Unchanged rows keep their widgets and only their age labels follow the clock. With 75 threads, a refresh went from 5.05 ms to 0.07 ms. The minute tick runs only while the window is shown.
- [perf] **Probes run only when their data is due.** Regaining focus used to refetch every model list and account (about 24 probe rounds an hour). Model lists now refresh hourly (15 minutes when the picker opens) and account status every 10 minutes, with live quota updates resetting the clock. A signed-out agy is probed only by Check again. The usage indicator dims a reading as it ages ("Last read HH:MM (N min ago)") and shows could-not-read once it has expired, rather than staying green.
- [perf] Indicator results are logged at info only when their state changes.

### Security and robustness

- [change] **The agy approval hook is proven afresh before every launch.** `--dangerously-skip-permissions` is passed only after a fresh check, run right before each spawn, of every hooks file agy will really read. That covers the profile's own `HOME` (which may differ from the app's), `~/.gemini/hooks.json`, every plugin hooks file under `~/.gemini`, and any `.agents/hooks.json`, `hooks/hooks.json` or `.agents/plugins/<p>/hooks.json` in the thread folder or an ancestor up to the repository root. Writes made meanwhile are held. A launch environment that redirects agy's data directories, an unreadable file, or a plugin root that cannot be listed refuses the flag. `--gemini_dir`, `--app_data_dir` and the one-dash skip flag are stripped from profile arguments. A refused check starts agy hookless with a notice that says why.
- [change] **Streaming redaction.** A new stream sanitiser publishes streamed text only once `redact()` can no longer change it, so a credential split across two deltas is never shown or stored in part. Every buffer, stream count and key is bounded.
- [change] **Store upgrades are guarded.** Before migrating, the store checks that its folder belongs to you (tightening only the app's own folder to `0700`), resolves the database through symlinks, refuses any unversioned file that is not empty, and checks every file's identity through the backup and the migration. Control writes for delegation are committed with `synchronous=FULL`.
- [change] **Profiles have stable ids**, assigned on first start, with duplicates repaired.
- [change] `rustls` updated to 0.23.46 for RUSTSEC-2026-0346 to 0349, and minor and patch updates to `cc`, `futures` and `toml`.

## Fixed

### Queued messages and sessions

- [fix] Stopping, restarting, switching or reloading an agent no longer sends the queued message to the old process, reorders the queue, or lets a new message jump ahead of it.
- [fix] A queued message recalled with Up leaves nothing behind in the store or a later hand-off.
- [fix] A model retired mid-turn is applied at the next turn boundary instead of restarting the running turn.
- [fix] Prompts written before Claude refused the thinking flag are sent again after the retry.
- [fix] A control sent to a dead Claude or Codex process is answered at once, and a panel request expires after 30 seconds.
- [fix] A switch whose new agent cannot start clears its pending model and effort before rolling back.
- [fix] No session starts on a window that is closing. An unsent first prompt there is kept, redacted.

### Windows, threads and diffs

- [fix] A thread open in one window is brought forward instead of opened twice. The sidebar says "open in another window", and switch, archive and delete reach the owning window.
- [fix] The reopen list keeps every window's threads, drops a window closed on its own, and keeps the last window at quit.
- [fix] "Switch this thread to" forks when the thread's own agent is missing or switched off, and waits while it is still being detected.
- [fix] Switching agents asks first whenever closing would (a running turn, background work, a pending approval).
- [fix] An earlier turn's "View diff" no longer uses a later turn's baseline.
- [fix] Thread-menu entries with nothing to offer are greyed out instead of opening empty submenus.
- [fix] Pasting over Settings → Diff Tool's command no longer clears the saved tool on the way. It saves once the edit is over, and only if valid.
- [fix] Settings → Agents command and env-file edits are debounced, saved on close, and stale scans dropped. The "Worktree Root" help text renders.
- [fix] A thread created or resumed while the store is slow reports that it may still be saved, and appears once it is.

### Undo, checkpoints and diffs

- [fix] Undo leaves alone a file that git now ignores and that exists in the working tree, and lists it as such.
- [fix] Checkpoints capture edits to files marked assume-unchanged, without touching the real index.
- [fix] A repository path containing a line break is refused with a clear message.
- [fix] File-change cards and approval previews say when a side was cut at 512 KiB.
- [fix] Codex's +N/-N counts follow hunk headers, so lines starting with `+++` or `---` and blank context lines count.
- [fix] Hand-off briefs redact each prompt and reply before capping them.

### Approvals and modes

- [fix] An agy "Allow for session" or "Always allow" is kept only once the hook accepted the reply. A dropped client ends the card as Expired with a notice.
- [fix] An agy mode change applies to its approval hook at once without ending the turn, and denies pending cards the new mode forbids.
- [fix] The shelf's Deny and Allow buttons stay in place between requests, and the shelf takes room only while an approval is shown.

### Chat view and adapters

- [fix] A second paragraph in a list item starts on its own line.
- [fix] The context gauge clears when the agent or model really changes, not on the first model report. agy's gauge follows the last call's context instead of a running total.
- [fix] Enter, Up, Down, Tab and Esc go to the input method while a pre-edit is open.
- [fix] The rate-limit notice shows the reset as a local time or date.
- [fix] Compact usage tags read 5h, wk, 2d…. The header usage chip hides when its agent is not shown.
- [fix] The sub-agent list shows full names and its Active/History headings instead of one letter per line and blank gaps. Unknown workers are counted apart from finished ones, and a stopping worker stays active until it exits.
- [fix] Claude's stop produces one notice, not two. Codex questions with identical text get their own answers.
- [fix] Chips and button rows are no longer measured at zero width (about 11,000 GTK warnings a week in the journal).
- [fix] Concurrent probes coalesce only for the same program and environment, and a model picker opened before the first scan refreshes once agents are found.
- [fix] A newer write of one model cache no longer causes another cache's write to be skipped.

## Testing

The suite now runs on cargo-nextest through `make test`, `make check` (CI's required gate and every release) and `make coverage`, with a private Xvfb, D-Bus session and XDG directories per run. Releases publish only when coverage passes on the release commit. New scenario tests drive Settings, the thread menu, busy-thread dialogs and a real scripted agent process the way a user does. Mutation testing runs weekly in CI only. `make test-one`, `make test-stress` and `make bench` were added for focused, repeated and measured runs.

## Upgrade and install

Settings, threads and approval rules are retained; the store is migrated after a verified backup (see Before you upgrade). Download the appropriate package and SHA256SUMS from this release, verify its checksum, then install it:

| Distribution | Command |
|---|---|
| Debian 13, Ubuntu 24.04 or newer | `sudo apt install ./agent-terminal_3.5.0-1_amd64.deb` |
| Fedora 40 or newer | `sudo dnf install ./agent-terminal-3.5.0-1.x86_64.rpm` |
| Arch Linux | `sudo pacman -U ./agent-terminal-3.5.0-1-x86_64.pkg.tar.zst` |

To use delegation, turn on "Agents can use each other as sub-agents" in Settings → Agents, approve agy's registration review if you use it, and reopen existing threads to attach their bridge.

## Known limitations

- **Codex as a sub-agent** (0.161.0) still starts its own built-in sub-agents despite its disable settings, and those run outside Agent Terminal's depth, mode and worktree limits. The worker dock shows them, capabilities report `route_caveats: ["codex_native_workers_unsupervised"]`, and Settings says so where you turn delegation on.
- **agy children need the managed bridge.** There is no fallback to an agy child without one; capabilities report the withheld route and why.
- Busy delivery to a child differs by provider and is reported as strict, best effort or unsupported. The app owns supervised processes; there is no detached daemon, so closing the app ends every child.
- A hook file created between agy's fresh hook check and agy reading its hooks is not seen by the proof. The canary bounds this: the first watched tool step with no hook query restarts agy without the skip flag after 8 seconds.
- The separate homelab `cross-agent` command is unchanged and not replaced.
