Agent Terminal 3.3.0 delivers session stability improvements, Write tool card and diff enhancements, Total Diff viewer target branch comparisons, and a redesigned animated header menu.

## Added

- **Target Branch Total Diff Viewer**: Added a `Target branch` comparison base to the right-side diff panel (`Ctrl+Shift+D`), allowing full inspection of all changes across all files against the primary branch (`origin/HEAD`, `main`, or `master`).
- **Animated Header Menu**: Replaced the previous plus-menu combination with an animated hamburger icon that smoothly rotates inwards to vertical lines when the menu opens and restores upon closing.
- **Antigravity Continuation Action**: Integrated token-exhaustion and rate-limit detection for Antigravity, offering an immediate continuation action into an alternative configured agent.

## Changed

- **Header Button Layout**: Separated the quick thread creation button (+) from the main menu, placing the menu button first followed by the quick start action.
- **Branding Consistency**: Standardised all user-facing references to use "Antigravity" across preferences, menus, and status surfaces.
- **Menu Simplification**: Removed superfluous duplicate thread creation options from the bottom of the main menu.

## Fixed

- **Session Crash on Hook Denials**: Prevented hook canary timeouts from falsely tripping and terminating sessions when commands or tools are denied by pre-tool hooks or fail before execution. Extended the canary grace window from 3s to 8s to accommodate heavy system load.
- **Write Card Action Label**: File modification cards now explicitly announce "Write" for file creations and "Edit" for modifications, keeping file paths in the summary.
- **Antigravity Diff Fallback**: Eliminated "No diff is available for this edit" errors by adding an on-disk read fallback generating unified diffs against empty baselines for new and untracked files, and properly resolving relative paths against the thread working directory.

## Upgrade and install

Existing settings and threads are retained. Download the appropriate package and SHA256SUMS from this release, verify its checksum, then install it:

| Distribution | Command |
|---|---|
| Debian 13, Ubuntu 24.04 or newer | `sudo apt install ./agent-terminal_3.3.0-1_amd64.deb` |
| Fedora 40 or newer | `sudo dnf install ./agent-terminal-3.3.0-1.x86_64.rpm` |
| Arch Linux | `sudo pacman -U ./agent-terminal-3.3.0-1-x86_64.pkg.tar.zst` |
