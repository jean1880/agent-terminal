Agent Terminal 3.0 is chat-first. Claude Code, Antigravity (`agy`) and Codex run as native chat
threads, with approvals, plans, diffs and undo built in, and a thread can move between them
mid-conversation. Terminal pages remain for any other CLI.

## Added

- **Chat threads for three agents.** A sidebar of threads, grouped by folder and searchable, each
  with its agent, age and a badge (working, needs approval, rate limited, unread). Recent Claude
  and agy sessions you ran in their own CLIs appear there too, with their history.
- **Switch agents in the middle of a conversation.** One model picker covers every Claude,
  Antigravity and Codex model. Picking another agent's model hands the thread over with a summary
  of the conversation so far: budgeted, redacted, fenced so tool output cannot pass for your
  words, and kept until the new agent has answered once, so a restart or a failed first turn does
  not lose it. A switch while the agent works asks first; a new agent that cannot start takes the
  thread back to the old one.
- **Codex** as a chat agent (app-server adapter, models, quota and account).
- **A native transcript**: markdown and code, tool and file-change cards with their diffs,
  approvals showing the proposed change ("Always allow" says exactly what it keeps), a plan panel,
  questions with answers to pick, running sub-agents, and a composer with `/`, `@` and `$`
  typeahead.
- **Usage and account at a glance**, per agent, in the thread header and the sidebar, and a
  banner when an installed agent has nobody signed in.
- **Themes**: the bundled Agent Terminal theme and six classics now style the whole app, and
  **Use System Theme** follows your desktop's GTK theme (light or dark, accent, `gtk.css`).
- **First-start setup**: a short walkthrough of your agents (installed, on or off, signed in,
  default for new threads), rerun from Settings → General → Setup.
- **Fedora and Arch packages**, beside the Debian/Ubuntu one.

## Changed

- Every new session opens as a chat thread. **+** → New Terminal Thread gives a 2.x terminal page
  with any profile.
- The theme setting moved to Settings → General → Appearance.
- The app ID is now `ca.nuvek.AgentTerminal`: re-pin a launcher you pinned before.

## Safety

- agy runs with `--dangerously-skip-permissions` only when its approval hook is proven installed;
  without it, Ask is unavailable and the app says plainly that agy still edits files on its own.
  An automatic hand-off never lands on such an agy while the thread does not allow unasked edits.
- Every stored event and every hand-off is redacted; threads live in
  `~/.local/state/agent-terminal/threads.db`.

## Upgrading from 2.x

Your `config.json` keeps working: profiles still define each agent's command, arguments and
environment file, and the new per-agent settings are optional (Settings → Agents). Install agy's
approval hook if you want it to ask before acting (Settings → Agents shows the entry).

## Install

| Distribution | Package |
|---|---|
| Debian 13, Ubuntu 24.04 or newer | `sudo apt install ./agent-terminal_3.0.0-1_amd64.deb` |
| Fedora 40 or newer | `sudo dnf install ./agent-terminal-3.0.0-1.x86_64.rpm` |
| Arch Linux | `sudo pacman -U ./agent-terminal-3.0.0-1-x86_64.pkg.tar.zst` |

Checksums are in `SHA256SUMS`. Then install and sign in to at least one agent CLI: Claude Code
(`claude`), Antigravity (`agy`) or Codex (`codex`).

## Known issues

- Codex session history from its own CLI is not imported yet; Codex threads started here work.
- After switching to Use System Theme while the app runs, messages already on screen keep their
  old inline-code colours until they are redrawn.
