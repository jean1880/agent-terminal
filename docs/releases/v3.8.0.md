Agent Terminal 3.8.0 is the final release from this repository. The project has moved to [jean1880/nuvek-agent-terminal](https://github.com/jean1880/nuvek-agent-terminal), where development continues from version 1.0.0, and this repository is archived. Apart from the hand-off below, 3.8.0 carries a fix for continued Claude sub-agents, which now show on a sub-agent card after a restart, plus dependency and CI updates.

## The move

- **New home:** [github.com/jean1880/nuvek-agent-terminal](https://github.com/jean1880/nuvek-agent-terminal). Issues, releases and packages are published there from now on.
- **Versions restart at 1.0.0.** The new repository's first release is 1.0.0, not 4.0.0.
- **Packages upgrade normally.** The new distribution packages carry epoch 1, so `apt`, `dnf` and `pacman` treat 1.0.0 as newer than any 3.x version and upgrade in place.
- **Users on 3.7.0 or earlier** are offered 3.8.0 by the in-app update check, and these notes tell them about the move.
- **From 3.8.0, move to 1.0.0 yourself.** Download 1.0.0 from the [new repository's Releases page](https://github.com/jean1880/nuvek-agent-terminal/releases), and install the 1.0.0 package with your package manager (`apt install ./…`, `dnf install ./…` or `pacman -U …`): its epoch 1 makes it an upgrade over 3.x.
- **The in-app update check will not prompt for 1.0.0.** It compares plain version numbers, so 1.0.0 is never newer than 3.8.0 to it.

## Fixed

- [fix] A Claude sub-agent continued after a restart now shows on a sub-agent card.

## Changed

- [change] Dependency updates (21 cargo crates) and GitHub Actions updates.
- [change] The package metadata's repository and homepage now point at the new repository. Nothing else about the app changes.

## Upgrade and install

Settings, threads and approval rules are retained, and the store is not migrated. Download the appropriate package and `SHA256SUMS` from this release, verify the checksum, then install it:

| Distribution | Command |
|---|---|
| Debian 13, Ubuntu 24.04 or newer | `sudo apt install ./agent-terminal_3.8.0-1_amd64.deb` |
| Fedora 40 or newer | `sudo dnf install ./agent-terminal-3.8.0-1.x86_64.rpm` |
| Arch Linux | `sudo pacman -U ./agent-terminal-3.8.0-1-x86_64.pkg.tar.zst` |

To remove it later, run `agent-terminal --uninstall`.
